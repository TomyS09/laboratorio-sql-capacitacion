# Prueba local para el instructor

Por seguridad del navegador, no abra `index.html` con doble clic. Debe servirse mediante HTTP.

Desde esta carpeta ejecute:

```bash
python -m http.server 8000
```

Luego abra:

```text
http://localhost:8000
```

La prueba local también necesita internet para descargar DuckDB-Wasm desde jsDelivr.
